Conceptos de redes

Router

Es un dispositivo que conecta redes y dirige los datos hacia su destino.

Dirección IP

Es una dirección lógica que permite identificar un dispositivo en una red IP.

DNS

Traduce nombres de dominio, como ejemplo.com, a direcciones IP.

¿Qué es Internet?

Internet es una red mundial de redes que permite intercambiar información y utilizar servicios como páginas web, correo electrónico y videollamadas.

Seguridad informática

La seguridad informática busca proteger los dispositivos, las redes y la información frente a accesos no autorizados y otras amenazas.
